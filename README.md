# 3DNanoForces

A collection of MATLAB analysis and plotting scripts for exploring three-dimensional nanoparticle trajectories, optical trapping, and colloidal electrokinetic flows.

The scripts were developed for two publications and analyse particle trajectories generated by [3D-image-processing](https://github.com/BorisLouis/3D-image-processing). That repository performs the upstream image processing and tracking and produces `trackResults.mat`; 3DNanoForces uses those results for quantitative analysis and plotting. Start with the data-analysis and plotting scripts listed below; the remaining functions support plotting, colour mapping, and distribution visualisation.

## Main analysis and plotting scripts

### ACS Nano 2023

Scripts in `ACS Nano paper 2023/`:

| Script | Purpose | Starting data |
| --- | --- | --- |
| `calcForce.m` | Select trajectories approaching the trap, calculate velocity or force estimates, and plot spatially binned vector fields and axial profiles. | `trackResults.mat`; update the trap centre and physical parameters. |
| `LocDensity.m` | Select incorporation trajectories and construct localisation-density maps and a 3D occupied-volume representation. | `trackResults.mat`; update spatial bounds and bin sizes. |
| `plotTraceSpeed.m` | Visualise a selected trajectory and collect axial speed values from retained trajectories. | `traces2Keep` and a three-component trap centre `CM` in the workspace; update the selected trace index. |
| `SpeedDistribution.m` | Compare distributions across four prepared speed datasets. | Workspace arrays `allSpeedR300`, `allSpeedR500`, `allSpeedR1000`, and `allSpeedR2000`. |

### Small 2026

Scripts in `Small 2026/`:

| Script | Purpose | Starting data |
| --- | --- | --- |
| `ConcentrationAndTrapping.m` | Estimate control particle concentrations, build localisation-density maps, identify trapping events, and plot event counts, speeds, vector fields, and concentration profiles. | Tracking results and control folders containing `particle.mat`. |
| `Histogram3D.m` | Bin localisations in 3D and inspect slices, interface maps, and rotated projections. | `trackRes` in the workspace. |
| `dataVis.m` | Display 3D trajectories coloured by normalised time within each trajectory. | `trackRes` in the workspace. |
| `PlotTraces.m` | Plot trajectories and selected traces; includes an animated GIF section. | `trackRes`; configure the output filename before exporting. |
| `PlotTraces_nDEP1V.m`, `PlotTraces_pDEP075V.m` | Generate condition-specific trajectory views for negative and positive dielectrophoresis experiments. | `trackRes`; adapt view limits, sampling fractions, and timing. |
| `nDEP_singleTraces.m`, `pDEP_singleTraces.m` | Inspect individual trajectories over localisation maps and display manually selected examples of particle motion. | `trackRes`; replace dataset-specific trace indices. |
| `PolarCoord.m` | Explore binned vector fields and streamline views. | `FullPos` produced by a preceding velocity-analysis section. |
| `exportPython.m` | Export trajectories to an HDF5 `/tracks` dataset for downstream analysis. | `trackResults.mat`; configure the output filename. |

### Additional scripts in the repository root

- `mainForceField.m`: calculate and visualise spatial velocity or force fields from `trackRes` already loaded in the workspace.
- `mainForceField_Sayan.m`: additional concentration, trajectory-filtering, and cumulative-trapping analyses.
- `plotTrapStatistic.m`: visualise selected trajectories and generate particle-motion animations.

Supporting functions include `quiverC3D.m`, `distributionPlot.m`, `distrib.m`, `colorCode2rgb.m`, and `getColorFromCmap.m`. They are called by the analysis scripts and normally do not need to be run separately.

## Input data

Most scripts use `trackResults.mat` generated by [3D-image-processing](https://github.com/BorisLouis/3D-image-processing). This MAT-file contains a structure named `trackRes`. Its `traces` field is a cell array, with a trajectory table in the first column:

```matlab
load('PATH_TO_DATA/trackResults.mat', 'trackRes');
trace = trackRes.traces{1, 1};
```

The main table fields are:

| Field | Meaning in the scripts |
| --- | --- |
| `col`, `row`, `z` | Spatial coordinates, generally expected in nanometres. |
| `t` | Frame index, converted to elapsed time using the frame interval. |
| `rT` | Time values used by some concentration analyses, converted from milliseconds to seconds with `/1000`. |

Some scripts also use recording identifiers from the second column of `trackRes.traces`. The control-concentration calculation reads per-frame detection counts from `particle.nParticles` in `particle.mat`.

The repository contains analysis code; experimental MAT-files must be supplied separately.

## Getting started

First process and track your microscopy data using [3D-image-processing](https://github.com/BorisLouis/3D-image-processing) to obtain `trackResults.mat`. If you already have this file, start directly with the steps below.

1. Download or clone the repository:

   ```bash
   git clone https://github.com/BorisLouis/3DNanoForces.git
   ```

2. In MATLAB, open the folder for the relevant paper. Keep its supporting functions accessible. Work with one paper folder at a time because several function names are duplicated across folders.

3. Open the script matching the analysis you need. Update its data paths and experimental settings, including frame interval, spatial calibration, trap position, filtering thresholds, bin sizes, and selected trajectory indices.

4. Load `trackRes` manually if the script assumes it is already in the workspace. Scripts with their own `load` section should instead have that section configured for your data.

5. Execute the required `%%` sections in order and inspect intermediate plots and variables. These scripts share workspace variables and include dataset-specific exploratory sections, so they are intended for selective, interactive use.

## Requirements and interpretation

- MATLAB. A minimum tested release is not specified.
- Image Processing Toolbox for density-map masking, morphology, and image rotation.
- Additional dependencies may be needed for selected plotting or statistical routines.
- The optional surface-smoothing section of `LocDensity.m` calls a `+rendering3D` package and C sources that are not included here. Supply that package to use this section, or work with the preceding density maps.

Velocity calculations generally convert nanometres to micrometres and use a frame interval in seconds. Drag-force estimates use Stokes' law, with viscosity in Pa·s and particle radius in metres. Check the physical parameters, coordinate conventions, and timing for each dataset before interpreting quantitative results. The acceleration-force branches are exploratory and require review before reuse.

Most results remain in MATLAB workspace arrays and figures. Save or export the outputs relevant to your analysis. Animation sections write GIF files when their output paths are configured.

`exportPython.m` writes columns `[id, t, x, y, z]`. In its current implementation, `t` is normalised separately to each trajectory's duration, and spatial coordinates are copied unchanged. Update its unit metadata or conversion code as appropriate; the existing HDF5 time attribute says seconds despite this normalisation. The script replaces an existing file with the configured output name.
